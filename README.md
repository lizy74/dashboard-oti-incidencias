# Sistema de Registro de Incidencias - UNAP OTI

Sistema web para el registro y gestión de incidentes tecnológicos de la Universidad Nacional del Altiplano.

## 🚀 Características

- **Gestión de Incidentes**: Crear, editar, visualizar y eliminar incidentes
- **Roles de Usuario**: Administrador y Practicante
- **Dashboard Personalizado**: Estadísticas y gráficos según el rol
- **Historial de Ediciones**: Auditoría completa de cambios
- **Importación CSV**: Carga masiva de incidentes
- **Reportes**: Exportación a Excel/CSV
- **Gestión de Practicantes**: CRUD completo
- **Paginación Dinámica**: Vista en tarjetas con diseño profesional

## 📋 Requisitos

- Python 3.8 o superior
- pip (gestor de paquetes de Python)

## 🔧 Instalación

1. **Clonar el repositorio o descargar los archivos**

2. **Crear entorno virtual (recomendado)**
